# Spatial feature analysis of the NSCLC tumor microenvironment

Notebook from the TECBio REU 2026 at PredxBio / University of Pittsburgh.

`predxbio_spatial_features_PrishaBhanushali.ipynb` loads cell segmentation output (gzipped JSON) for each patient, converts each cell's polygon into a table of centroid position, area and eccentricity, and plots the cells over the matching H&E image.

Input data are not included in this repository.
